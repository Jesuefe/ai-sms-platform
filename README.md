# AI SMS Platform

One-page test console for Bulk-SMS.ng promotional SMS.

## Setup
1. Copy `.env.example` to `.env.local`.
2. Add your Bulk-SMS.ng email and password.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

Credentials stay on the server and are never sent to the browser.

For the first test, use a phone number you own or have permission to message. Bulk-SMS.ng accepts up to 100 recipients per request according to its API documentation.
